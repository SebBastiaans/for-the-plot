# For The Plot

I want to make a website for me and my friends where we can see which places in the world we have visited. I want to have a hero with an interactive world globe which I can grab and spin. On this globe you see which countries that we've crossed off. If you click on on of the countries you move to a detailpage where you can see al lot of information about when, where, who etc. have been to that place.
